<h1>不停问 · dont-stop-ask</h1>

**一个从不替你回答问题的青少年研究工具。**

给它一个粗糙的题目——比如「美国对中国的关税会怎样影响世界？」——它会返回一张更好的问题地图：每个问题都
挂着真实且经过核实的阅读材料，每个问题都附带一个在开始阅读**之前**要做的核查动作。你在地图上探索，遇到
真正有意思的问题时，把它再展开成九个。

它不总结材料，不代写论文，也不告诉你该站哪一边。这是设计，不是缺陷。

[English](README.md) · [试用示例](#试用示例) · [完整范例](examples/us-china-tariffs/)

## 为什么做这个

学生实际做的研究通常是：搜索、略读、改写、加引注。而真正能学到东西的研究是：把问题磨锋利、找出谁在反对、
弄清每项研究究竟**测量**了什么，然后给出一个能当面为之辩护的立场。

会总结材料的 AI 只是让第一种更快。这个工具试图让第二种成为可能——办法是把常见的助手模式反过来。研究助手
替你默默核查来源，因为你本来就会核查；而在这里，**核查本身就是课程**，所以凡是工具能替你做的判断，都被交
还给你，变成一个你要亲自执行的动作。

两项研究结论决定了整个设计：

- 专业事实核查员判断一个陌生来源只需约 90 秒，方法是**离开当前页面**，去看独立来源怎么说。学生——以及
  教授——却习惯在页面内往下读，追逐那些轻易就能伪造的线索，花五倍的时间，却更常出错
  （Wineburg & McGrew, 2017, 2019）。
- 自己生成解释的效果远胜于反复重读，但前提是已有足够背景知识去生成解释（Pressley et al., 1992;
  Woloshyn et al., 1994）。所以问题的顺序很重要，过早出现的难题只会换来沉默。

## 五条铁律

每一套问题都在这些规则下生成，它们高于其他一切指令：

| | 规则 | 原因 |
|---|---|---|
| 1 | **绝不编造来源** | 真实作者 + 真实期刊 + 看似合理的年份，是最危险的幻觉：搜一下作者名字，看起来就像核实过了 |
| 2 | **绝不回答自己提出的问题** | 如果这套问题让你不打开任何材料就能完成作业，那它已经失败了 |
| 3 | **给动作，不给结论** | 不说「这家智库拿了行业资助」，而说「搜它的名字加 *funding*，然后你自己判断」 |
| 4 | **不用引导性问题** | 两个同样了解情况的学生，必须能得出不同却都站得住的答案 |
| 5 | **不做伪装的记忆题** | 「关税是什么？」是检索；「为什么一个国家会明知抬高本国物价还要征关税？」才是探究 |

当某个来源无法核实时，它会**标注为 unconfirmed** 出场，并明确写出到底哪一部分没能确认。示例里就有一个。
这是正确的结果，不是缺陷——而且给家长的简报会告诉大人：抽查就从这里开始。

## 运作方式

```
  你的粗糙题目
        │
        ▼
  /HTeen-Research  ──── 在 Claude Code 中运行，需联网搜索
        │                 · 磨锋利问题（并展示推导过程）
        │                 · 生成最多 9 个问题，覆盖 7 种问题类型
        │                 · 每个问题配 1–3 份分级阅读材料，逐一搜索核实
        │                 · 按相关度分组，按难度分级
        ▼
  三个文件 ────────────┬─── question-set.md    供大人审阅的完整记录
                       ├─── question-set.json  学生可见版：不含答案（由 schema 强制）
                       └─── research-briefing.md   大人真正会读的那份
                                │
                                ▼
                          viewer/  ── 把 JSON 渲染成力导向图
                                      点圆点 → 阅读材料 + 怎么读
                                      点展开 → 把该问题长成另外 9 个
```

**Claude Code 是引擎，这个仓库是技能和地图。** 核实来源需要联网搜索，所以生成发生在 Claude Code 会话里，
而不是浏览器里。查看器是纯静态的——不需要服务器，不需要 API key，没有任何东西要部署。

## 安装

需要 [Claude Code](https://claude.com/claude-code) 和 Python 3（仅用于校验脚本和本地预览）。

```bash
git clone https://github.com/USER/dont-stop-ask.git
```

然后把技能装进 Claude Code：

```bash
cp -r dont-stop-ask/skills/HTeen-Research ~/.claude/skills/
```

Windows PowerShell：

```powershell
Copy-Item -Recurse dont-stop-ask\skills\HTeen-Research $HOME\.claude\skills\
```

## 使用

在 Claude Code 会话中生成一套问题：

```bash
claude "/HTeen-Research 咖啡因究竟如何影响睡眠？学生情况：17岁，生物课程，出于好奇而非作业"
```

三个文件会写进 `./question-sets/`。打开图谱：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/viewer/?data=../question-sets/你的文件.json`。

直接用浏览器打开 `viewer/index.html` 也可以——浏览器禁止读取本地文件，所以页面会显示一个拖放区，
把 JSON 拖进去一次即可。

**展开某个问题：** 点它的圆点，按*Copy expansion prompt*，粘贴回 Claude Code。它会对这个问题重跑一遍
问题阶梯，复用已核实过的来源，核实新增的来源，然后写出一份包含全部内容的新 JSON。刷新查看器，新分支就出现了。

## 七种问题类型

一套问题必须覆盖全部七种，并向**机制**和**张力**倾斜——校园研究最常死在这两处。学生只收集「是什么」，
从不走到「为什么」；而一套内部没有真实分歧的问题，无论引了多少来源，产出的都只是读书报告。

| | 类型 | 它教的动作 |
|---|---|---|
| 1 | 含义 | 我们到底在问什么？哪些词在起作用？ |
| 2 | 全景 | 谁研究过这件事，他们发现了什么？ |
| 3 | **机制** | 为什么会这样？底下的故事是什么？ |
| 4 | **张力** | 谁不同意，他们最有力的理由是什么？ |
| 5 | 证据 | 人怎么可能知道这件事？什么算是证明？ |
| 6 | 边界 | 这个说法在哪里开始不成立？ |
| 7 | 意义 | 谁在意？如果答案反过来，什么会改变？ |

张力卡必须呈现**真实存在**的分歧，并且以其最强的形态呈现。如果某个题目本身没有活跃的专家分歧，技能被要求
直接说明这一点，而不是制造一场争论。

## 给大人的部分

每套问题都配一份为**完全不懂这个学科的人**写的简报。它是分层的：读完第一屏就能在十分钟内行动；想要推理过程
就继续往下读。它给你三个可以在饭桌上直接问出口的问题、真正理解与背书之间的区别听起来是什么样、你会听到的
词汇表，以及最关键的一部分——如何核查我们的引注，并从我们自己没能确认的那一条开始。

问题集出场时状态是 `status: draft`，改成 `adult-approved` 是审阅的交接动作。这只是一个靠自觉的约定；
技能文档的 Known Limitations 里写明了它有多脆弱。

## 它不会做的事

不写论文。不给论点大纲。不出草稿。不告诉任何人该站哪一边。不通过总结材料来让阅读可以被跳过。

可被检验的标准：**如果这个青少年最后拿到的是自己没法当面辩护的东西，那就出了问题**——简报里那三个复述
问题就是你查明真相的办法。

## 依赖它之前值得知道的局限

1. **各个部件证据充分，整体组合尚未验证。** 横向阅读、生成式追问、核心问题设计、以教促学，各自都有扎实证据；
   把它们组装成这个东西是一次有理据的赌注，而不是经过验证的干预方案。
2. **核实的可靠性取决于背后的搜索。** 技能能确认一个来源存在、且其摘要支持所附的说法。它读不了付费墙后的
   全文，也可能被一个真实、收录良好却错误的来源骗过。
3. **数字比引注更容易走失。** 在技术性题目上，更大的风险不是假引注，而是真数字脱离了它的适用范围——
   「损失 140 亿美元」指的是某一年上半年、且仅限货物贸易。简报里明确写了这一点。
4. **它无法判断有没有人真的读了。** 它改变激励、让对话中的空洞暴露出来，但它不强制任何事。
5. **尚未制定敏感题目的内容政策。** 当前版本假定由大人挑选题目、并在学生看到之前审阅来源。这个假定承担了
   实质性的责任，补上它是当前第一优先。
